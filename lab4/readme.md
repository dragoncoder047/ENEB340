# what is this

`lab4-1.c` - computes factorial with `register` and without `register` to test speed (run `./speedtest`). segfaults if there is no argument.

`lab4-2.c` - converts base 10 number in argv[1] to binary. segfaults if there is no argument.

`lab4-3.c` - temperature-sensor simulator - generates some not-very-random fake temperature readings from a nonexistent temperature sensor and bins them into "ok", "something's wrong with the thing the sensor's measuring", and "something's wrong with the sensor". the argv controls the behavior of the fake readings (whether they include abnormal or failure readings, and how many readings to run).
